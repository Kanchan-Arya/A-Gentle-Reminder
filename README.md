## 💗 About the Project

**A Little Light** is a simple, aesthetic website created to bring a little positivity into your everyday life.

This little corner of the internet is a reminder to slow down, breathe, believe in yourself, and appreciate the beautiful little things in life.

Sometimes, all we need is a little light. 🌷

## 🛠️ Built With

- **HTML5** — Structure and content
- **CSS3** — Styling, colors, gradients, and layout
- **JavaScript** — Interactive elements and positivity messages
- **GitHub Pages** — Website hosting

## 🚀 Run Locally

Want to explore the project on your computer?

1. Clone this repository:

   ```bash
   git clone https://github.com/kanchan-arya/a-little-light.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser, or use the **Live Server** extension in VS Code.

That's it! No complicated setup required. 🌼

## 🎀 Project Philosophy

> “You don't have to bloom every day. Sometimes, simply growing is enough.”

This project was created with a simple thought: positivity doesn't have to be loud or complicated. A kind word, a peaceful moment, or a gentle reminder can make a difference.

May this little website remind you that you are growing, you are learning, and you deserve kindness — especially from yourself. 💗
